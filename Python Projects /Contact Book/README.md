# Contact Book App

A simple contact management program made using Python. Users can add, view, search, update, and delete contacts using a menu-driven system. Contact details are stored using dictionaries.

## Features

* Add new contacts
* View all contacts
* Search contacts
* Update contact details
* Delete contacts
* Basic input validation

## Technologies Used

* Python
* Dictionary
* Functions
* CRUD Operations

## How to Run

1. Download the project files
2. Open the Python file
3. Run the program

```python
python contact_book.py
```

## Project Type

Console-based Python application.
